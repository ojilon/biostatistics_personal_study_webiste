Core Theory

Data Integrity in the Field

The statistical validity of any biostatistical analysis is bounded by the quality of primary data collected in the field or laboratory. Field Data Collection requires systematic protocols to minimize measurement error, eliminate observer bias, and maintain data integrity prior to statistical computation.

📌 Decomposition of Observed Measurements

Every recorded biological measurement ($x_{\text{observed}}$) consists of the true parameter value plus systematic and random error components:

$$x_{\text{observed}} = x_{\text{true}} + \epsilon_{\text{systematic}} + \epsilon_{\text{random}}$$

Where $\epsilon_{\text{systematic}}$ reduces accuracy (bias) and $\epsilon_{\text{random}}$ reduces precision (repeatability).

Quality Control

Managing Error in Biological Sampling

1

Systematic Error (Bias)

Consistently shifts readings in one direction. Caused by uncalibrated scales, faulty environmental sensors, or biased sampling frame selection.

Remedy: Daily instrument zero-point calibration against known reference standards.

2

Random Variation

Unpredictable fluctuation caused by micro-environmental shifts, temperature swings, or slight variations in operator technique.

Remedy: Increasing sample size ($n$) and standardizing environmental measurement timing.

3

Observer Bias

Expectation bias where an evaluator unconsciously scores treated groups higher than controls.

Remedy: Double-blind evaluation where data collectors do not know treatment codes.

📱 Practical Case Study: Mobile Data Collection via ODK / KoboToolbox

A research team deployed digital field forms using ODK Collect across 120 smallholder cassava farms in Masaka District:

  • Quality Control Rules Implemented:
    • Range Constraints: Plant height constrained between $0.2\text{ m}$ and $4.5\text{ m}$ to prevent entry typos (e.g., typing 25m).
    • Mandatory Photo Capture: Automatic geotagging and plant photo capture for disease score validation.
    • Real-Time Auditing: Submissions synced daily to a central cloud server for rapid oversight by senior biostatisticians.

Result: Data entry errors were reduced by 94% compared to traditional paper-based field sheets, eliminating manual data re-keying.

💡 Knowledge Check

Question: A field technician measures blood glucose levels in cattle using an uncalibrated glucometer that constantly reads $0.8\text{ mmol/L}$ higher than actual values. Does this issue affect the accuracy, the precision, or both metrics of the resulting dataset?

Answer: This uncalibrated instrument introduces Systematic Error (Bias), which directly degrades Accuracy (closeness to the true value). The Precision (repeatability of measurements) may remain high if repeated tests yield identical offset values, but every value remains shifted systematically upward.
