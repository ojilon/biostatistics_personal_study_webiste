Core Theory

Organising Raw Biological Data

A frequency distribution summarises how often each value (or class interval) occurs. For continuous data we form class intervals and build a histogram. For categorical data we use a bar chart. The cumulative frequency curve (ogive) helps locate percentiles.

📌 Class Interval Formula

Approximate number of classes (Sturges):

$$k = 1 + 3.322 \log_{10} n$$

Class width $w \approx \dfrac{\text{Range}}{k}$

🌽 Field Practical: Grouping Maize Yields

A researcher records 48 maize plot yields (t/ha). Range is $2.1$–$5.8$. Using Sturges’ rule:

$$k = 1 + 3.322 \log_{10} 48 \approx 6.6 \rightarrow 7 \text{ classes}$$

Class width $w \approx (5.8-2.1)/7 \approx 0.53$ (often rounded to $0.5$). The histogram shows whether yield is approximately normal or skewed — critical before choosing a parametric test.

💡 Knowledge Check

Question: Why should the vertical axis of a histogram start at zero, and what happens if class intervals have unequal widths?

Answer: Starting at zero prevents visual exaggeration. Unequal widths make bar area no longer proportional to frequency; plot density (frequency/width) instead of raw frequency.
