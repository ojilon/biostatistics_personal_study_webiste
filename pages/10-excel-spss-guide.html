Step-by-Step

Common Workflows

1

Excel: Enable ToolPak

File → Options → Add-Ins → Excel Add-ins → check Analysis ToolPak. Then use Data → Data Analysis.

2

SPSS: Variable Types

Variable View: set Measure to Scale, Ordinal, or Nominal; assign Value Labels for treatment codes.

3

SPSS: Independent $t$-Test

Analyze → Compare Means → Independent-Samples T Test. Test Variable(s) = outcome; Grouping Variable = treatment.

💻 Interpreting SPSS Independent $t$-Test Output

  • Levene's: $F = 0.842$, $p = 0.364$ → equal variances assumed.
  • $t = 3.142$, $df = 28$, $p = 0.004$.
  • Mean difference: $0.24$ kg/day ($95\%$ CI: $[0.08, 0.40]$).

Reject $H_0$ ($p = 0.004 < 0.05$). Feed B gained significantly more weight.

💡 Knowledge Check

Question: Levene's Sig. $= 0.012$. Which $t$-test row do you report?

Answer: Report "Equal variances not assumed" (Welch's $t$). Levene's $p = 0.012 < 0.05$ means equal-variance assumption is violated.
