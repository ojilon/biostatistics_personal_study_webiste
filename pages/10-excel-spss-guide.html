Core Theory

Computational Biostatistics

Modern biostatistical analysis relies on software platforms to compute complex mathematical models efficiently. While Microsoft Excel provides accessible options for field data logging and baseline summaries, IBM SPSS Statistics offers a dedicated environment for assumption testing, non-parametric analysis, and multifactor ANOVA.

📌 Tidy Data Structuring Rule

1. Each variable forms a single column.

2. Each biological observation forms a single row.

3. Each cell contains a single measurement value.

Step-by-Step Execution

Common Analytical Workflows

1

Excel: Enabling ToolPak

Navigate to File → Options → Add-Ins. Under Manage, select Excel Add-ins, click Go, check Analysis ToolPak, and press OK. The Data Analysis tool will appear under the Data tab.

2

SPSS: Setting Variable Types

In Variable View, define variable names, set Measure to Scale (numeric continuous), Ordinal (ranked ratings), or Nominal (categories), and assign Value Labels for treatment codes.

3

SPSS: Running Independent t-Test

Select Analyze → Compare Means → Independent-Samples T Test. Move the measurement metric to Test Variable(s) and treatment category to Grouping Variable. Define group codes and run.

💻 Practical Case Study: Interpreting SPSS Independent t-Test Output

A trial evaluated cattle daily weight gain (kg) under two feed regimes (Feed A vs Feed B):

  • Levene's Test for Equality of Variances: $F = 0.842$, $p = 0.364$. Since $p > 0.05$, equal variances are assumed.
  • t-Test Output (Equal Variances Assumed): $t = 3.142$, $df = 28$, $p = 0.004$.
  • Mean Difference: Feed B increased daily gain by $0.24\text{ kg/day}$ ($95\%\text{ CI: } [0.08, 0.40]$).

Conclusion: Reject $H_0$ ($p = 0.004 < 0.05$). Animals on Feed B gained significantly more weight than those on Feed A.

💡 Knowledge Check

Question: When reading an SPSS Independent Samples $t$-test output table, Levene's Test reports Sig. ($p$-value) $= 0.012$. Which row of $t$-test output should you report, and why?

Answer: You must read and report the bottom row labelled "Equal variances not assumed" (Welch's $t$-test). Because Levene's test is significant ($p = 0.012 < 0.05$), the assumption of equal population variances is violated, making standard pooled $t$-tests invalid.
