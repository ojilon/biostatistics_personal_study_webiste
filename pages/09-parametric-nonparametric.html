Core Theory

The Test Selection Framework

Statistical tests fall into two major paradigms. Parametric tests make strict underlying assumptions about the population parameters (such as normality and equal variance) and offer higher statistical power when assumptions are met. Non-parametric tests make fewer distribution assumptions, operating on ranks or counts, and are robust against non-normality, small samples, and ordinal data.

📌 Parametric Assumptions Checklist

1. Measurement Scale: Continuous interval or ratio scale.

2. Normality: Sample data drawn from a normally distributed population.

3. Homogeneity of Variance: Equal group variances ($\sigma_1^2 = \sigma_2^2$).

4. Independence: Observations sampled independently.

Diagnostic Tools

Testing Parametric Assumptions

1

Shapiro-Wilk Test

Formal statistical test for normality. Best suited for smaller biological sample sizes ($n < 50$).

$$p > 0.05 \implies \text{Data is normally distributed}$$

$$p \le 0.05 \implies \text{Violates normality assumption}$$

2

Levene's Test

Evaluates equality of variances (homoscedasticity) across two or more treatment groups.

$$p > 0.05 \implies \text{Equal variances assumed}$$

$$p \le 0.05 \implies \text{Unequal variances (use Welch's test)}$$

3

Visual Inspection (Q-Q Plot)

Quantile-Quantile plots compare observed data points against expected theoretical normal values along a straight 45-degree reference line.

🐛 Field Practical Case Study: Crop Disease Severity Ratings

An agronomist records cassava mosaic disease severity scores on an ordinal scale ($1 = \text{Healthy}$, $5 = \text{Severe}$) across two farming practices ($n_1 = 12$, $n_2 = 12$):

  • Data Scale: Ordinal Likert-type scale (non-continuous data).
  • Test Selection: Because the variable is ordinal and skewed, an independent $t$-test is invalid. The Mann-Whitney $U$ Test is selected.
  • Calculated Outcome: $U = 22.5$, $p = 0.014$.

Conclusion: Since $p = 0.014 < 0.05$, there is a statistically significant difference in median disease severity ranks between the two farming practices.

💡 Knowledge Check

Question: You measure daily milk yields ($N=15$) from a local herd. A Shapiro-Wilk normality test yields $p = 0.003$. Should you use an Independent $t$-Test or a Mann-Whitney $U$ test to compare this group against a second herd?

Answer: You must use the Mann-Whitney $U$ Test. The Shapiro-Wilk test rejected normality ($p = 0.003 < 0.05$), indicating severe skewness in a small sample size ($N=15$). Parametric $t$-tests are unreliable under non-normal distributions with small sample sizes.
