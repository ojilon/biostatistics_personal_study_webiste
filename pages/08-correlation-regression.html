Core Theory

Modeling Biological Relationships

In biological systems, variables rarely act in isolation. Correlation evaluates the strength and direction of a linear association between two continuous variables. Simple Linear Regression models the mathematical functional relationship, enabling prediction of a dependent response variable ($Y$) from an independent predictor ($X$).

📌 Regression & Correlation Equations

Pearson Correlation Coefficient ($r$):

$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}}$$

Linear Regression Model:

$$\hat{Y} = \beta_0 + \beta_1 X$$

Association Analysis

Pearson vs. Spearman Correlation

Feature Pearson Correlation ($r$) Spearman Rank Correlation ($\rho$)
Data Type Requirement Continuous (Interval or Ratio) scale Ordinal or non-normally distributed Continuous scale
Relationship Evaluated Linear relationship Monotonic relationship (general trend)
Assumptions Bivariate normality, homoscedasticity, no extreme outliers Non-parametric (no normality assumption required)
Value Range $-1.0 \le r \le +1.0$ $-1.0 \le \rho \le +1.0$
Biological Application Correlating temperature vs plant transpiration rate Correlating disease severity grade vs soil quality rank

Predictive Modeling

Simple Linear Regression Anatomy

1

Slope ($\beta_1$)

Represents the expected change in response variable $Y$ per unit increase in predictor variable $X$.

$$\beta_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}$$

2

Intercept ($\beta_0$)

Represents the predicted baseline value of $Y$ when the predictor variable $X = 0$.

$$\beta_0 = \bar{Y} - \beta_1 \bar{X}$$

3

Goodness of Fit ($R^2$)

The Coefficient of Determination ($R^2$) quantifies the proportion of total variation in $Y$ explained by $X$.

$$R^2 = (r)^2 \quad (0 \le R^2 \le 1.0)$$

🌽 Field Practical Case Study: Fertilizer vs. Maize Yield

An agronomist at Namulonge evaluates the impact of nitrogen fertilizer application ($X$, kg/ha) on maize grain yield ($Y$, t/ha):

  • Fitted Regression Equation: $$\hat{Y} = 2.15 + 0.038 X$$
  • Correlation Coefficient: $r = 0.89$ ($p < 0.001$)
  • Coefficient of Determination: $R^2 = (0.89)^2 = 0.792 \text{ (or } 79.2\%)$

Interpretation: Baseline unfertilized yield is $2.15\text{ t/ha}$. Each additional $1\text{ kg/ha}$ of nitrogen increases grain yield by $0.038\text{ t/ha}$. Nitrogen application explains 79.2% of the variance in maize yield.

💡 Knowledge Check

Question: A researcher calculates a Pearson correlation coefficient of $r = -0.84$ between tick count per animal and daily weight gain (grams). What does this negative coefficient mean, and does it prove that ticks cause weight loss?

Answer: The value $r = -0.84$ indicates a strong inverse linear relationship: as tick count increases, daily weight gain significantly decreases. However, correlation does not imply causation; confounding factors like poor nutrition or underlying disease could simultaneously increase tick susceptibility and decrease weight gain.
